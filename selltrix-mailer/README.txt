SELLTRIX MAILER / Windows 11

Это исходный комплект с окном, не скомпилированный EXE.
Реальные письма уходят только после вашего подтверждения.

УСТАНОВКА
1. Полностью распакуйте ZIP в C:\SelltrixMailer. Не запускайте из архива.
2. Установите Python 3.11 или новее с https://www.python.org/downloads/windows/.
   В установщике оставьте Tcl/Tk (tkinter) и Python Launcher.
3. Откройте Терминал Windows и выполните:
   winget install --id astral-sh.uv -e
   Подтвердите установку uv и закройте Терминал.
4. Дважды нажмите START.bat. При первом старте uv скачает зависимости.
   База контактов никуда при установке не передаётся.
5. Введите пароль приложения ff@selltrix.ru. Пароль хранится только в памяти
   на время операции. После теста/партии введите его заново.

EXCEL
В вашей книге на листе «Очищенный список» добавьте столбец approved.
Поставьте ДА только у выбранных адресов с подтверждённым согласием на рекламу.
Остальные строки оставьте пустыми. Сохраните книгу и закройте Excel.
Либо используйте лист «К отправке» с колонками email, company, approved, Флаги.
Образец example.xlsx содержит вымышленные адреса; отправлять на них не нужно.
Импорт принимает один адрес на строку, исключает дубли и все строки с флагами.
Если в книге есть листы аудита, исправленные/спорные адреса исключаются также
по этим листам. Не удаляйте листы аудита при подготовке очищенной книги.
Исправление адреса не подтверждает существование ящика или согласие.

РАБОТА
1. Проверьте тему, текст, подпись и ссылку в окне. Текст можно редактировать.
   Изменения в окне не сохраняются после закрытия; для постоянных правок
   редактируйте letter.txt (UTF-8). Письмо обычное текстовое, Word не прикладывается.
2. Нажмите «Загрузить Excel», затем «Предпросмотр без отправки». Он показывает
   доступные и исключённые адреса, не подключается к SMTP и не меняет журнал.
3. Нажмите «Тест себе», введите свой второй адрес, подтвердите одно письмо.
   Тест отправляется сразу, вне расписания, но учитывается в дневном лимите.
4. Проверьте получение, ссылки и ответ на ff@selltrix.ru.
5. Проверьте число разрешённых и исключённых строк в окне.
5. Прочитайте входящие в Яндекс.Почте. Все отписки и постоянные недоставки
   добавьте через «Стоп-лист +». Автоматического чтения входящих нет.
6. Укажите часы по времени Windows, лимит попыток в день, интервал в секундах.
   По умолчанию 10–17 часов, 20 попыток, интервал 180 секунд. Это ограничение
   пилота, а не безопасный лимит Яндекса. Правила провайдера имеют приоритет.
7. Подтвердите согласия и проверку отписок, нажмите «Запустить партию».
   В подтверждении показаны отправитель, тема, количество и первые адреса.
8. Оставьте окно открытым, ПК включённым, сон отключённым. До начала окна
   программа ждёт. После конца окна/лимита/полуночи нужна новая ручная партия.
   Выходные автоматически не исключаются. Пропущенные часы не догоняются.
9. СТОП прекращает новые отправки; уже начатый SMTP-запрос отменить нельзя.
   После остановки проверьте входящие перед новым запуском.

ЖУРНАЛ
journal.sqlite3 хранится рядом с программой. Не удаляйте и не заменяйте его:
он защищает от повторов и хранит стоп-лист. При обновлении сохраните этот файл.
Не запускайте копии программы из разных папок: у них будут разные журналы.
smtp_accepted = принято сервером, не доказательство доставки во «Входящие».
reserved / uncertain_or_failed = возможная отправка или ошибка; повтор заблокирован.
При любой SMTP/сетевой ошибке партия останавливается. Проверьте почту/ограничения
и журнал. Автоматического повтора неопределённых отправок нет, кнопки сброса нет.
Адрес, уже записанный в основной кампании, повторно не отправляется даже после
изменения текста. Тесты отдельные и могут повторяться по вашему подтверждению.
Все попытки, включая тесты и ошибки, учитываются в дневном лимите.
Журнал в окне показывает последние 500 попыток; полная история остаётся в SQLite.

ПРЕДЕЛЫ
Отправка только через smtp.yandex.ru:465 с проверкой TLS и входом ff@selltrix.ru.
Не обходить ограничения сервиса. Гарантии отсутствия блокировок нет.
Нет автоматической обработки IMAP/отписок/жалоб: входящие проверяйте вручную.
Наличие email в Excel не подтверждает согласие на рекламную рассылку.
Лимит 100 — верхняя граница настройки пилота, не рекомендация объёма.
База/пароль не включены в ZIP. Защитите доступ к папке и резервным копиям журнала.
На Linux проверяется логика. Запуск BAT и подключение вашего аккаунта на Windows
требуют локального теста, до него не запускайте клиентскую партию.

АВТОЗАПУСК
1. Откройте SelltrixMailer, введите пароль приложения и нажмите «Сохранить пароль
   для автозапуска». Пароль попадёт в Credential Manager текущего пользователя
   Windows, а не в файлы, журнал или Планировщик заданий.
2. В Excel должны остаться только согласованные контакты с approved=ДА. До
   настройки расписания вручную обновите стоп-лист и проверьте preview.
3. Откройте PowerShell в C:\SelltrixMailer и выполните:
   .\INSTALL_SCHEDULE.ps1 -ConfirmApprovedRecipients -ConfirmStopListReviewed
4. Задача запускается ежедневно в 10:00 только пока этот пользователь Windows
   вошёл в систему. Пропущенный запуск не догоняется, параллельный запуск
   игнорируется, пароль в параметры задачи не передаётся.
5. Для проверки без SMTP выполните: .\RUN_SCHEDULED.bat --dry-run
   или: uv run scheduled.py --dry-run
